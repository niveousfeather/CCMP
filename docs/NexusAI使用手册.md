# NexusAI 网站使用手册

> 版本：2026-05-06  
> 适用对象：平台普通用户、教师用户、管理员  
> 适用范围：NexusAI 首页、工作台、Nexus Agent、图片生成、视频生成、3D 工作区、历史记录、用户管理与数据分析。

## 1. 平台简介

NexusAI 是一个统一的 AI 创作工作台，把对话写作、联网检索、图片生成、视频生成、3D 资产生成、知识图谱、历史资产管理和管理员数据分析集中在同一个网站中。

用户登录后可以从左侧导航进入不同功能模块；管理员账号会额外看到“数据分析”和“用户”入口。

## 2. 登录与首页

### 2.1 首页入口

打开网站首页后，可以查看平台介绍、轮播展示和主要创作能力入口。首页保留登录入口和环境/主题切换按钮。

> 截图位置：`docs/assets/manual/home.png`  
> 说明：请在正式部署或本地预览环境截图后替换。

### 2.2 登录

1. 点击首页右上角“登录”。
2. 输入管理员创建的账号和密码。
3. 点击“进入工作台”。
4. 登录成功后自动进入“今日工作台”。

> 截图位置：`docs/assets/manual/login.png`

注意事项：

- 账号由管理员统一创建。
- 第一次登录后建议进入“设置”修改密码。
- 如果提示账号或密码错误，请联系管理员重置密码。

## 3. 工作台

工作台用于快速查看今日创作状态、额度使用情况和常用入口。

主要区域：

- **平台/个人视角**：管理员显示平台视角，普通用户显示个人视角。
- **额度脉冲**：显示图片生成、视频生成、3D 生成的今日已用次数和剩余次数。
- **快捷入口**：快速进入 Nexus Agent、图片生成、视频生成、知识图谱；管理员还可进入数据分析和用户管理。
- **最近任务**：展示近期创作记录。
- **状态中枢**：展示当前可用模型和服务状态。

建议操作：

1. 每天开始创作前先查看“额度脉冲”。
2. 长任务提交后不要重复点击生成按钮，可进入历史记录查看状态。
3. 需要统一管理结果时，优先从“历史记录”进入。

## 4. Nexus Agent

Nexus Agent 是平台的智能对话与创作中枢，支持普通问答、联网搜索、写作、PPT、图像生成和文件理解。

### 4.1 新对话

1. 左侧点击“Nexus Agent”。
2. 在输入框输入问题或任务。
3. 点击发送按钮。

输入框支持：

- 普通文本提问。
- 上传图片、PDF、Word、Excel、CSV、文本、视频等资料。
- 开启“联网搜索”后参考最新网络资料回答。
- 切换“帮我写作”“PPT生成”“图像生成”等创作模式。

### 4.2 联网搜索

当问题涉及最新政策、实时资料、天气、新闻、市场数据等内容时，建议打开“联网搜索”。

使用方式：

1. 点击输入框下方“联网搜索”。
2. 输入需要检索的问题。
3. 发送后等待 Agent 返回答案与引用信息。

### 4.3 写作与 PPT

适合生成：

- 教案、方案、汇报、通知、总结。
- PPT 大纲、课程课件结构、演示文稿内容。

使用建议：

- 尽量说明目标读者、使用场景、字数或页数。
- 如果有资料，请先上传文件再提问。
- 生成结果可继续要求“压缩成一页”“改成正式风格”“生成表格版”。

### 4.4 图像生成

在 Agent 对话中选择“图像生成”后，可以直接用自然语言生成图片。生成中的图片会以卡片形式显示，完成后可预览。

## 5. 知识图谱

知识图谱用于把主题、资料和知识点整理成可视化结构。

入口：

- 左侧 Nexus Agent 下的“知识图谱”。
- 工作台快捷入口“知识图谱”。

使用方式：

1. 输入主题，例如“三维动画教学知识图谱”。
2. 可上传资料辅助分析。
3. 点击生成。
4. 在画布中拖动、缩放、查看节点说明。
5. 右侧或历史区域可查看和删除知识图谱记录。

适用场景：

- 课程知识结构梳理。
- 项目资料关系整理。
- 教学主题拆解。
- 调研资料快速结构化。

## 6. 图片生成

图片生成支持文生图和部分模型的图生图/图片编辑。

### 6.1 基本流程

1. 左侧点击“图片生成”。
2. 选择模型。
3. 可选上传参考图片。
4. 输入 Prompt。
5. 选择风格、比例、分辨率。
6. 点击“立即生成”或“生成编辑结果”。
7. 等待任务完成后，在中间结果区或右侧历史区查看。

### 6.2 支持参数

常用参数：

- **模型**：Nexus Image2、Nexus Image mini2 等。
- **风格**：默认、未来建筑、产品海报、极简界面、品牌视觉。
- **比例**：1:1、16:9、9:16、4:3、3:4。
- **分辨率**：1K、2K、4K。
- **参考图片**：支持 jpg、jpeg、png、webp。

注意事项：

- 并非所有模型都支持参考图；界面会提示“仅文生图”或“可选”。
- 图片生成中时，历史记录应显示“生成中”，请等待轮询完成。
- 生成结果会进入图片历史；配置 OSS 后，结果链接会持久保存。

## 7. 视频生成

视频生成支持文本生成视频，也支持上传参考图驱动视频。

### 7.1 基本流程

1. 左侧点击“视频生成”。
2. 可选上传参考图片。
3. 输入视频 Prompt，描述主体、动作、镜头、场景和节奏。
4. 选择模型、时长、比例、分辨率。
5. 点击“生成视频”。
6. 任务提交后等待生成完成。
7. 完成后可播放预览或下载。

### 7.2 支持参数

当前前端显示参数：

- **模型**：Nexus Video3.0。
- **时长**：当前模型支持 5s、10s。
- **比例**：16:9、9:16、1:1、4:3。
- **分辨率**：当前模型支持 720P，1080P 暂不支持。
- **参考图片**：支持 jpg、jpeg、png、webp。

注意事项：

- 视频属于长任务，生成期间请不要重复提交同一任务。
- 任务进行中时，视频页面和历史记录会显示“生成中”。
- 如果生成失败，可查看历史记录中的失败原因。

## 8. 3D 工作区

3D 工作区用于生成、预览、编辑和管理 3D 模型资产。当前工作区已接入任务提交、历史资产、模型预览、导出 UI 和 Tripo 钱包/任务接口相关逻辑。

### 8.1 页面结构

3D 工作区由三部分组成：

- **左侧功能区**：模型生成、部件拆分、部件补全、重拓扑、纹理生成、动画等工具。
- **中间视口**：预览 3D 模型，支持旋转、缩放、移动视图、网格、环境设置、材质显示模式。
- **右侧面板**：资产、属性、历史记录。

### 8.2 模型生成

支持入口：

- 单图生成。
- 多视图生成。
- 批量图片生成。
- 文本生成。

基本流程：

1. 进入“3D工作区”。
2. 在左侧选择“模型”。
3. 选择“高精度模型”或“智能网格”。
4. 选择输入方式：单图、多视图、批量、文本。
5. 按界面提示上传图片或输入描述。
6. 选择标准纹理、高清纹理、标准结构、精细结构等参数。
7. 选择 AI 模型版本。
8. 点击“生成模型”。

模型版本前端显示：

- Nexus 3D 3.1：对应官方最新 P1.0 模型。
- Nexus 3D 3.0：对应官方 V3.0 模型。
- Nexus 3D 2.5：对应官方 V2.5 模型。

注意事项：

- 3D 生成通常需要 2–5 分钟，请等待任务完成。
- 生成中状态会保留在资产/历史记录中。
- 避免连续重复点击生成按钮，以免产生重复任务和费用。

### 8.3 上传本地模型预览

中间视口支持上传已有模型文件用于预览。

支持格式：

- GLB
- GLTF
- FBX
- OBJ

限制：

- 单个模型文件大小上限为 80MB。
- 不同格式的材质、贴图和动画支持程度可能不同。

### 8.4 纹理生成与子模块

左侧点击“纹理生成”后，会展开子模块：

- 纹理编辑。
- 纹理放大。
- PBR。

纹理生成支持：

- 上传图片。
- 多视图上传。
- 文本描述。
- 标准纹理/高清纹理选项。

纹理编辑支持：

- 生成模式：通过文本描述生成或修改纹理。
- 绘制模式：用于后续遮罩/绘制式编辑。

纹理放大用于提升已有贴图模型的纹理分辨率。

PBR 用于为已有贴图模型创建更真实的物理材质效果。

### 8.5 部件与属性

右侧“属性”面板展示当前模型层级。

默认概念：

- 默认选中整个模型。
- 只有展开父级层级并点击子层级后，才会单独选中子部件。
- 后续接入 API 的部件拆分后，会形成父子层级关系。

属性面板可查看和调整：

- 位置。
- 旋转。
- 缩放。
- 层级显示。

### 8.6 3D 视口操作

中间视口支持类似 3D 软件的观察方式：

- 鼠标右键：旋转视口。
- 鼠标滚轮：缩放视图。
- 鼠标中键：平移视口。
- 右上角坐标轴：显示当前视角方向。
- 网格：显示世界地面参考。

视口功能：

- 环境设置：切换 HDRI 环境、调整强度、旋转环境光、自动旋转环境光。
- 重置相机：恢复初始观察角度。
- 网格：开启或关闭地面网格。
- 材质模式：白模、纹理视图、显示设置、无光照、法线、卡通风格、素描风格、全息风格。

### 8.7 导出模型

点击视口底部右侧“导出”按钮，可打开导出卡片。

支持参数：

- 文件命名。
- 格式选择：FBX、OBJ、STL、GLB。
- 分辨率选择。
- 底部中心轴点：可将导出模型轴点移动到底部中心。

注意事项：

- 导出能力需要官方 API 支持对应格式。
- 如某格式暂不可用，应以后端返回为准。

### 8.8 资产与历史

右侧“资产”面板用于展示 3D 生成历史资源。

资产功能：

- 生成或编辑完成后展示预览。
- 鼠标悬停可查看生成或编辑时间。
- 点击资源可加载到视口。
- 右下角“...”可删除资源。
- 顶部“管理”支持批量导出和批量删除。

右侧“历史记录”面板用于记录模型大步骤操作，例如：

- 修改模型结构。
- 修改模型贴图。
- 执行重拓扑。
- 执行 PBR。
- 变换模型位置、旋转、缩放。

点击历史步骤可回退到该步骤；选择历史版本后，顶部会出现“当前版本”按钮，用于回到选择前版本。

## 9. 总历史记录

“历史记录”页面统一展示当前账号的图片、对话、视频和 3D 资产历史。

支持筛选：

- 全部。
- 图片。
- 对话。
- 视频。
- 3D。
- 我的收藏。
- 状态筛选：已完成、生成中、活跃、生成失败。

常用操作：

- 点击图片记录可打开预览。
- 点击对话记录可回到对应会话。
- 点击视频记录可进入视频页预览。
- 点击 3D 记录可进入 3D 工作区加载资产。
- 可收藏或取消收藏支持的记录。
- 可删除历史记录。

注意事项：

- 生成中的任务在历史页应显示“生成中”，不是“生成失败”。
- 3D 资产配置 OSS 后，刷新页面仍应能恢复历史资产链接。

## 10. 用户管理

用户管理仅管理员可见。

入口：

- 左侧“用户”。
- 工作台快捷入口“用户管理”。

功能：

- 添加单个用户。
- 批量导入用户。
- 搜索用户。
- 按角色筛选。
- 修改用户角色。
- 重置用户密码。
- 删除用户。
- 批量删除。
- 查看 Tripo 钱包余额。
- 配置角色每日配额。

### 10.1 角色

当前角色：

- 管理员：拥有用户管理、数据分析和平台级查看权限。
- 教师：普通创作权限。
- 学生：普通创作权限。

### 10.2 角色每日配额

管理员可以设置不同角色每天可提交的任务次数：

- 图片生成次数。
- 视频生成次数。
- 3D 生成次数。

配额用于限制每日提交次数，避免误操作或过度消耗上游额度。

### 10.3 Tripo 钱包余额

用户管理页面会显示 Tripo 钱包余额信息：

- 可用余额 balance。
- 冻结金额 frozen。
- 可用额度 credits。

如果余额查询失败，请检查服务器环境变量中的 Tripo API Key 和网络连通性。

## 11. 数据分析

数据分析仅管理员可见，用于运营监控和异常排查。

入口：

- 左侧“数据分析”。
- 工作台快捷入口“数据分析”。

包含内容：

- 今日请求。
- 任务成功率。
- 失败任务。
- 平台用户。
- 近 7 天使用趋势。
- 功能使用分布。
- 任务状态分布。
- 错误请求日志。
- 每日明细表。
- 活跃用户排行。
- 存储与资产概览。

使用建议：

- 每天查看失败任务和错误日志，及时定位上游 API、OSS、超时或并发问题。
- 观察图片、视频、3D、Agent 的使用分布，辅助调整角色配额。
- 上线后将数据分析页作为平台健康检查入口。

## 12. 设置

设置页面用于修改当前账号密码。

操作流程：

1. 左侧点击“设置”。
2. 输入旧密码。
3. 输入新密码。
4. 再次确认新密码。
5. 点击“保存修改”。

要求：

- 新密码至少 8 位。
- 两次输入的新密码必须一致。

## 13. 主题与环境切换

页面右上角提供主题/环境切换按钮。3D 工作区也已适配浅色和夜间模式。

建议：

- 白天办公可使用浅色主题。
- 长时间查看 3D 视口或创作素材时，可切换夜间模式降低视觉疲劳。

## 14. 任务状态说明

常见状态：

- **生成中**：任务已提交，正在排队、重试或等待上游生成。
- **已完成**：生成成功，可预览或下载。
- **生成失败**：上游或服务器返回失败，可查看失败原因。
- **生成超时**：长任务超过等待时间，需要稍后刷新或重试。

长任务建议：

- 图片任务通常较快，但高分辨率可能更久。
- 视频任务和 3D 任务可能需要数分钟。
- 3D 任务常见等待时间为 2–5 分钟。
- 提交后请等待页面状态刷新，不要重复点击生成。

## 15. 资产存储说明

平台生成结果优先走 OSS 存储。

配置 OSS 后：

- 图片结果会保存稳定链接。
- 视频结果会保存稳定链接。
- 3D 模型和预览资源会保存稳定链接。
- 刷新页面后，历史记录仍可恢复资产。

如果刷新后资产丢失，请管理员检查：

- OSS 环境变量是否配置完整。
- 上传接口是否返回 objectKey。
- 数据库历史记录是否保存 URL 和 objectKey。
- 服务器是否有外网访问 OSS 的权限。

## 16. 常见问题

### 16.1 登录失败怎么办？

请确认账号密码是否正确。如果忘记密码，请联系管理员在“用户管理”中重置密码。

### 16.2 图片或视频一直显示生成中？

长任务会持续轮询状态。请等待一段时间后刷新历史记录。如果长时间无变化，请联系管理员检查队列、上游 API 和错误日志。

### 16.3 3D 生成扣费但没有看到模型？

请先进入“3D工作区”的资产面板和总“历史记录”的 3D 分类查看。如果仍没有结果，请管理员检查：

- `/api/model3d/tasks/[id]` 是否能查到任务。
- Tripo providerTaskId 是否保存。
- OSS 是否成功保存返回模型。
- 数据库 `Model3DGeneration` 是否有 `modelUrl` 或 `previewModelUrl`。

### 16.4 上传图片后页面变形怎么办？

当前上传预览窗口已做固定区域限制。如果仍出现异常，请更换更小尺寸图片或联系管理员检查前端样式。

### 16.5 为什么某些按钮是灰色或不可选？

通常表示当前模型或上游 API 暂不支持该参数，例如视频 1080P 或部分图片模型参考图能力。

### 16.6 导出模型失败怎么办？

请确认当前模型已生成完成，并确认官方 API 支持目标格式。若失败，请尝试 GLB 或联系管理员查看错误日志。

## 17. 管理员上线检查

上线前建议管理员确认：

- `.env` 已配置数据库、会话密钥、上游 API Key、OSS 参数。
- `TRIPO_API_KEY` 已填写。
- `TRIPO_TIMEOUT_MS` 留足 3D 长任务等待时间。
- Nginx / 反向代理已配置足够的读取超时时间。
- OSS Bucket 可写入且服务器可访问。
- 数据库迁移已执行。
- 管理员账号已创建。
- 图片、视频、3D 的生成中状态能在历史记录正确显示。
- 数据分析页能读取真实任务、用户、错误日志数据。
